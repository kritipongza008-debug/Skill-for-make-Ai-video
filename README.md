# Skill-for-make-Ai-video
# Clip Studio 3D — สกิลทำคลิปสั้นแนวตั้ง (TikTok / Reels / Shorts)

ทำคลิป 30–90 วินาที สไตล์ **3D-look แบบกระดาษตัดซ้อนชั้น** (มีมิติ ชั้นหน้า-หลัง พาราแลกซ์ เงา กล้องซูม/แพน) เหมือนคลิปตัวอย่าง "ถ้าเกิดเป็นเด็กช่าง" ทุกครั้ง ออกมาเป็นหน้าเว็บไฟล์เดียว มีปุ่ม **บันทึกเป็น MP4**

## ใช้ยังไง (3 ขั้น)
1. **ส่งเนื้อเรื่องมา หรือสั่งให้คิดให้** → ได้ "บทพูดฉบับดีที่สุด" กลับมาเลย (ไม่ใช่ลิสต์ไอเดียยาว ๆ) พร้อมคำแนะนำเสียง
2. **ไปเจนเสียงเอง** ที่ ElevenLabs (แนะนำเป็นอันดับแรกเสมอ): https://elevenlabs.io แล้วส่งไฟล์ mp3 กลับมา
3. **รับคลิปสำเร็จ** ซับตรงจังหวะ กล้องเคลื่อน เอฟเฟกต์เสียง เพลงพื้น (เบาลงตอนพูด) ตอนจบวนต่อต้นคลิปได้ + ลิงก์ให้ดู/เซฟ

## ทำอะไรได้บ้าง
| ความสามารถ | รายละเอียด |
|---|---|
| คิด/ปรับเนื้อเรื่อง | ฮุกประโยคแรก โครงเรื่อง ปมหักมุม จบด้วยคำถามที่ต่อประโยคแรกได้ เขียนเป็นภาษาพูดพร้อมส่งเข้า TTS |
| **ค้นข้อมูลทุกครั้ง** | ถ้าเรื่องมีข้อเท็จจริง (วันที่ ตัวเลข ประวัติศาสตร์ วิทยาศาสตร์ ฯลฯ) หรือคุณสั่งให้ค้น จะค้นเว็บก่อนเขียนเสมอ ไม่ข้าม และแนบแหล่งที่มา เรื่องที่ถกเถียงกันจะเล่าแบบ "เล่ากันว่า" |
| **ตั้งค่าบทแยกเสียงได้** | ค่าเริ่มต้น = คนเล่าคนเดียว ถ้าบอก "แยกเสียง/หลายตัวละคร/บทสนทนา" จะได้ ตารางตัวละคร (แนวเสียงที่ควรเลือก) + บทแยกตามคน `[A] [B]…` + ลิสต์เรียงเลขไฟล์ ซับจะเปลี่ยนสีตามคนพูด |
| ทางส่งเสียงแยก 2 แบบ | (ก) ไฟล์เดียวจาก Text to Dialogue ของ ElevenLabs (ก) เจนทีละบรรทัดแล้วส่งทุกไฟล์ `01_A.mp3 02_B.mp3…` สกิลรวมให้เอง (`merge_voices.py`) |
| ทำคลิปจากเสียงที่ส่งมา | ตัดช่วงเงียบ จัดซับตามเสียง ซีนกระดาษซ้อนชั้น เอฟเฟกต์/เพลงที่สังเคราะห์เอง (ไม่ใช้เพลงมีลิขสิทธิ์) |
| ตรวจก่อนส่ง (ปกติ) | สคริปต์ตรวจจังหวะ ซับ เสียง จุดจบ + ดูภาพตัวอย่าง + วัดความลื่น ใช้ token น้อย |
| **ตรวจละเอียด** | พิมพ์ **`ต้องตรวจให้ละเอียดก่อนส่ง`** → ตรวจทุกเฟรมสำคัญ ทุกจุดต่อการ์ด แล้ว **แก้และยกระดับ** ให้ถึงมาตรฐานคลิปตัวอย่างของคุณ (ชั้นความลึก, ตัวละครขยับ, เอฟเฟกต์ตรงจังหวะ, ความลื่น) รายงานตัวเลขก่อน→หลัง |
| แก้คลิปที่ทำแล้ว | บอกเลขวินาทีที่ไม่ตรง แล้วแก้ในลิงก์เดิม |

## ความลื่น (แก้จากเคสเซฟแล้วค้าง)
เงาเบลอและฟิล์มเกรนถูกถอดออกจากแกนกลาง, วาด 30 เฟรม/วินาทีเท่ากับตัวอัด, อัดบิตเรต 3 Mbps แบบเก็บเป็นช่วงสั้น ๆ, แคชขอบมืดและความกว้างข้อความ และมี `frame_cost.js` วัดความหนักของแต่ละเฟรมทุกครั้งที่สร้าง

## ประหยัด token ยังไง
`SKILL.md` สั้น (ตัวหลักที่โหลดทุกครั้ง) ส่วนรายละเอียดแยกเป็นไฟล์ใน `references/` โหลดเฉพาะโหมดที่ใช้ (STORY / BUILD / DEEP CHECK) ไม่แปะโค้ดลงแชท ไฟล์ตัวอย่างอ่านแค่ซีนเดียวเมื่อจำเป็น

## ข้อจำกัด (บอกตรง ๆ)
- "3D" คือภาพกระดาษตัดซ้อนชั้นมีมิติบน canvas ไม่ใช่เอนจิน 3D จริง
- สกิลทำเสียงพูดเองไม่ได้ ต้องเจนที่ ElevenLabs
- ฟัง/ดูเสียงจริงไม่ได้ จึงยืนยันไม่ได้ว่าเสียงเอฟเฟกต์ลงจังหวะเป๊ะหรือไม่ การบันทึก MP4 ในเบราว์เซอร์จริงต้องให้คุณลอง (ผมวัดได้แค่ความเร็ววาดใน node-canvas ใช้เทียบกันเท่านั้น)
- ความสามารถ Text to Dialogue ของ ElevenLabs อาจไม่ขึ้นในหน้าเว็บบางบัญชี (เอกสารหน้าหนึ่งบอกว่าผ่าน API) ถ้าไม่มี ให้ใช้ทางเจนทีละบรรทัด เอกสาร: https://elevenlabs.io/docs/overview/capabilities/text-to-dialogue
